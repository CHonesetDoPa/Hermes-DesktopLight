## Features

- Native Windows desktop application.
- Remote-only Light variant.
- No bundled local Hermes Agent payload.
- No bundled Python runtime.
- Designed to connect to an existing remote Hermes Gateway.

## Download

Download:

**Hermes-Desktop-Light-Windows-x64.zip**

## Installation

1. Download the ZIP file.
2. Extract the ZIP to any directory.
3. Open the extracted directory.
4. Run `Hermes.exe`.
5. Configure the remote Gateway connection.

No installer is required.

## Requirements

- Windows x64.
- A reachable remote Hermes Gateway.
- Network access to your remote Hermes server.
